# InnerNavi

병원 평면도에서 이동 그래프를 생성하고 접근 가능한 실내 경로를 안내하는 프로젝트입니다.

## Repositories

| Repository | Role | Status |
| --- | --- | --- |
| `innernavi-django` | Python·Django 중심의 주력 구현 | Initial scaffold |
| `innernavi-springboot` | 동일 도메인의 Spring Boot 비교 구현 | Initial scaffold |

두 구현은 동일한 문제와 평가 기준을 사용하되, 각 저장소에서 독립적으로 실행·검증·배포할 수 있도록 구성합니다.

세부 아키텍처, 데모, 측정 결과와 배포 증거는 구현 마일스톤이 완료될 때 갱신합니다.
